# EasyElevator Forge

Minecraft **1.20.1** · Forge **47.4.26** · Java **17 编译目标** · 模组 **2.3.3-forge-1.20.1**。

本工程由 EasyElevator 2.3.0（MC 1.21.1、Fabric Loader 0.19.2、Fabric API 0.116.17+1.21.1）独立移植。原 Fabric 工程保留。Forge 版不需要 Fabric Loader 或 Fabric API，客户端和服务器均需安装同版模组。

## 安装

1. 在启动器中选择 Minecraft 1.20.1 / Forge 47.4.26 实例。
2. 关闭游戏，把 `build/libs/easyelevator-2.3.3-forge-1.20.1.jar` 放进该实例的 `mods` 目录。
3. 从该实例移除旧的 EasyElevator JAR，避免同一模组重复加载。不要安装 `-sources.jar`。
4. 使用独立的 1.20.1 世界。此移植不包含 Minecraft 1.21.1 世界或物品数据组件的降级转换器。

## 搭建与使用

1. 创造物品栏「简易电梯」提供电梯轨道、电梯门，以及普通、高速、观光、重载四种轿厢；也可通过配方合成。
2. 垂直放置一列连续轨道，整列保持相同朝向。轨道朝向就是轿厢所在方向与门朝向。
3. 在轨道朝向前方 **3 格**、相同 Y 坐标放置电梯门的底部中心。一件物品生成 **3×3** 的整扇门。距离按方块坐标计算，每扇完整门对应一站。
4. 手持轿厢右键轨道。轿厢中心位于轨道前方 2 格，底部与点击的轨道同高。保持井道内部 3×3、轿厢高度 3 格的空间畅通。每条连续线路只能放置一台轿厢。
5. 普通右键楼层门打开厅外呼叫面板，选择上行或下行；端站只显示有效方向。已登记的方向显示红色，按实际到站服务情况熄灭。
6. 进入轿厢后右键打开选站面板，可选择楼层、翻页、开门或关门。开门操作只在停稳且站点完整等条件满足时接受；运行中的车门不能随意打开。
7. 潜行右键楼层门打开该门设置：设置基准层、到站提示音开关、预设音、试听或上传自定义音频。
8. 将某站设为基准层后，该站显示 1，其下为 B1、B2，其上为 2、3。没有基准层时最低站为 1。

## 四种轿厢

| 型号 | 巡航速度 | 空载限载 | 特点 |
| --- | --- | --- | --- |
| 普通 | 4 格/秒 | 8 人 | 标准内饰 |
| 高速 | 10 格/秒 | 8 人 | 加减速过程按高速参数计算 |
| 观光 | 4 格/秒 | 8 人 | 玻璃外观 |
| 重载 | 4 格/秒 | 20 人 | 27 格货舱，载客量随货物减少 |

停稳且门完全打开后，在重载轿厢内潜行右键打开货舱。装卸界面打开期间保持开门；关闭后恢复调度。货量按实际件数计，容器内部物品不递归计算。

- 每 128 件货物占用一个乘客名额，不足一档也计入；最多 1728 件，满载时剩 6 个乘客名额。
- 每 288 件显示一个货箱，最多六个；外观与碰撞使用同一几何。
- 后部货箱区域有人或动物时，不允许新货箱与其重叠；先让出区域再继续装货。
- 货物随轿厢保存；回收或杀死轿厢时掉落，区块卸载不掉落。

## 到站音效

每扇门可以独立开关、选择预设和上传 OGG 音频。可使用文件选择、输入路径或拖入文件，单文件不超过 **512 KiB**。自定义音频由服务端保存并同步给客户端；客户端自动生成并启用 `resourcepacks/easyelevator_custom` 资源包。

Forge 1.20.1 上传使用 24 KiB 分片，完整文件接收后才进行格式检查与保存。配置文件在游戏实例的 `config/easyelevator/arrival_sounds` 中。资源包格式为 15。

## 运行规则与排查

调度保留原版 2.3.0 的方向、车内请求和厅外呼叫语义；此移植没有另行实现新的调度策略。门未完全关闭、门口被挡或人数超载时不能发车。断轨、井道障碍、站点损坏或区块未加载会导致停止或暂停。模组不主动强制加载整条井道。

站点不识别时，检查门的九个部件、轨道朝向和三格距离；不能发车时检查超载、货舱界面、门口障碍与沿途轨道。联机时两端必须使用一致版本。
